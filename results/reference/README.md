# Archived evidence

CSV/JSON MC scores are fractions in [0,1]. `main_per_fold.csv` aligns test halves;
`main_averages.csv` provides macro and pooled values. Evidence IDs, recorded scores,
source hashes and original-path hashes are preserved; displayed paths use release
names. Repeated per-question copies were omitted from this compact package.

No full GPU rerun is claimed. Missing source records remain marked in
`audit_status.json`; original MMsafe inputs/judge and external vector baselines
are not bundled.
